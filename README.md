# FanControl
Electronic Components like CPUs are prone to damage on overheating which is why fans are employed to cool them. Temperature of a metal block (mimicking an electronic item) is controlled using a fan with PID Tuning to manipulate fan speed. Also presented here is the theoretical background of this Control Project.
